Superpowers, not bullet points.

The capabilities that make people switch — each one deep, each one real, each one running on your phone.

01

Voice mode

Talk instead of type. Full hands-free conversations with on-device speech recognition and downloadable voices that never leave your phone — tap to interrupt anytime. Nothing you say is processed in a cloud.

02

Privacy core

The Privacy Dashboard shows every network connection the app makes. Local-only mode blocks non-essential traffic, per-chat locks and biometric app lock keep snoopers out, and API keys live in encrypted storage. Zero analytics SDKs, zero trackers — provably.

03

Scheduled agents

Agents that work while you sleep. Describe routines in plain language and wake up to a morning briefing — weather, calendar, headlines — with tasks that keep running even when the app is closed.

04

Creator studio

A YouTube dashboard, clip captions, viral hooks and a title optimizer built into the chat. Research, script, title and caption your videos without ever leaving the conversation.

05

On-device AI

Download open models and chat in airplane mode — nothing you say leaves the phone. Offline-first routing and smart model selection keep answers fast whether you're connected or not.

06

Terminal & browser, with guardrails

A real Linux shell and a real browser live inside the chat — the agent can run commands, fetch pages and operate screens. Before anything irreversible — deleting, sending, paying — an approval card stops and asks you first.

07

Incognito & memory control

Start an incognito chat that leaves no trace, set per-chat auto-delete timers, and inspect every memory the agent keeps about you. Forgetting is a feature, not a bug.

08

Bring your own key

No account, no subscription, no lock-in. Paste a key from OpenAI, Anthropic, Gemini, DeepSeek, OpenRouter — or point it at your own local server. The key is stored encrypted on your device and goes straight to the provider you chose.
